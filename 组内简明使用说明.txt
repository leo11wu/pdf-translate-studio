纸间｜PDF 翻译工具简明使用说明

适用于 Apple 芯片 Mac（M1/M2/M3/M4 等），系统需为 macOS 14 或以上。无需安装 Python、Node 或使用终端。翻译时需联网，并使用自己的翻译服务额度。

一、下载与安装
1. 下载软件：
https://github.com/leo11wu/pdf-translate-studio/releases/download/v0.4.0/PaperStudio-0.4.0-macOS-arm64.zip
链接打不开时，请向组内维护者索取 ZIP 安装包。直接收到 ZIP 的同学不需要 GitHub 账号。
2. 双击 ZIP 解压，把“纸间.app”拖入“应用程序”文件夹，再双击打开。
3. 如果因“无法验证开发者”而被拦截：尝试打开后，进入“系统设置 → 隐私与安全性”，找到这款 App，点击“仍要打开”，再确认。只对组内提供、确认来源的这份 App 操作。
4. 首次打开会自动下载约 350 MB 的版式资源和字体。保持联网，等待显示“模型与字体已就绪”，无需手动安装。

二、首次配置 API（保存后通常不用再填）
API 就是 App 使用的翻译服务。请先准备好：服务地址、自己的 API 密钥、推荐模型名称；不清楚时请组内维护者协助。
1. 点击“新建配置”，展开“API 地址与钥匙串设置”；可给配置起一个容易辨认的名字，例如“我的 DeepSeek”。
2. 先粘贴“API 基础地址”，再粘贴“API 密钥”。密钥使用你自己的，不是网站登录密码。
3. 等待模型列表自动出现，在“翻译模型”中选择推荐的文本模型。列表没出现可点“刷新模型”；仍有问题请联系维护者。
4. 勾选“安全记住 API 密钥（macOS 钥匙串）”，点击“保存配置”。看到配置已保存的提示即可，以后打开会自动恢复。需要换服务商时，在“已保存的 API 配置”中选对应名称，地址、密钥和模型会一起切换；新增另一套请点“新建配置”。
请勿把 API 密钥发到群里，截图求助时也要遮住密钥。

三、翻译 PDF
1. 把一份 PDF 拖入 App，或点击“拖入 PDF，或点击选择”选文件。
2. 保持“同时导出原文 TXT 和译文 TXT”勾选，其余设置先用默认值。
3. 点击“开始译制”，保持 App 打开，等待显示“译制完成”。页数较多时需要更久。默认会自动调整请求并发；出现“上游限流，等待重试”时可先等待，进度百分比不代表剩余时间。

四、查看、下载结果
完成后默认自动保存到“下载 → 纸间译文”，每次任务都有单独的文件夹，内含中文 PDF、原文 TXT 和译文 TXT。
也可在 App 点击“输出与历史”，找到对应任务，点击“结果文件夹”。
想另选保存位置：点击结果旁的“另存”，选择文件夹后保存。
下次打开 App，还可以从“输出与历史”找到以前的任务；需要时点击“保存结果”重新保存。

五、只要原文文字时
选好 PDF，点击“仅提取原文 TXT（不调用 API）”。这一步不需要 API 密钥，也不消耗翻译额度。

小提示
• 点击“开始译制”后，翻译所需文字会发送到你配置的服务，并消耗个人 API 额度；App 不附带额度。
• 第一次建议用页数较少的 PDF 试译。扫描件、图片内文字和复杂表格可能无法正确处理；重要内容请对照原文，TXT 用于研究前也需核对。
• 遇到错误时，把报错文字或遮住密钥的截图发给维护者；不用自己修改代码或配置文件。

macOS 首次打开的官方说明：https://support.apple.com/zh-cn/102445

版本：纸间 0.4.0。升级会保留原稿、译文和任务历史，并自动迁移旧版最后保存的一套 API；旧版更早被覆盖的配置需重新添加。
