纸间 · PDF 译制台 0.3.0
Apple 芯片版 · macOS 14 或更高版本

安装与启动
1. 解压 ZIP，将“纸间.app”拖入“应用程序”，双击启动。
2. 此组内测试版采用本地临时签名，尚未经过 Apple 公证。如 macOS 阻止启动，可在尝试打开后前往“系统设置 → 隐私与安全性”，对本 App 选择“仍要打开”。只对你确认来源的这一份 App 操作。
3. 首次使用自动下载约 336 MB 的版式模型、字体和字符映射。可在下载期间配置 API。下载失败后点击“重试”，已完成并通过校验的文件会保留。

配置 API
1. 填写供应商提供的 OpenAI-compatible API 基础地址。例如 https://你的供应商/v1；自定义路径会保留。仅填写域名时会自动补 /v1。
2. 填写该地址对应的 API 密钥，App 会自动请求 /models 并展示模型列表。选择支持文本对话和 chat/completions 的模型；列表中可能也包含嵌入、图像等不适用于翻译的模型。
3. 若供应商没有模型列表接口，可手动填写模型名称。
4. 勾选“安全记住 API 密钥”后点击“保存配置”，密钥将保存到当前 Mac 用户的登录钥匙串。未勾选时，保存后密钥仅保留在当前 App 会话内；普通偏好设置中只保存地址、模型、并发数。
5. 修改 API 地址后需要重新填写对应密钥，App 不会将原地址的密钥自动发送到新地址。“忘记密钥”会删除钥匙串记录并清除当前会话的密钥。
6. 这是 OpenAI-compatible 接口客户端，供应商需提供兼容的 /chat/completions；原生 Anthropic、Gemini 等不同协议需使用其兼容端点。

翻译 PDF
1. 拖入或选择一份 PDF。当前目的语固定为简体中文。
2. 模型与字体就绪、API 配置完整后，点击“开始译制”。
3. 超过 80 页自动分段，完成后合并。高级设置可调并发及分段页数。
4. 默认生成纯译文 PDF。需要时可开启中英对照版；这会增加处理时间。
5. 默认在完成后自动保存到“下载/纸间译文”，每个任务使用“原文件名--日期-任务编号”文件夹，重名也不会覆盖已有结果。在“输出与历史”中可更改统一目录、关闭自动保存、重新保存或打开结果文件夹。单个文件仍可通过“另存”按钮另选位置。
6. 任务运行中退出 App 会先询问是否取消。当前版本没有断点续传；已下载的模型和字体不会因退出而删除。

TXT 与研究用途
1. 默认勾选“同时导出原文 TXT 和译文 TXT”。原文 TXT 来自原 PDF 的文本层；译文 TXT 来自最终中文 PDF 的文本层，不做第二次模型翻译。
2. 只需要原文时，选择 PDF 后点击“仅提取原文 TXT（不调用 API）”，无需配置密钥，也不消耗 API 用量。
3. TXT 使用 UTF-8，保留分页标记和原始换行，并对普通双栏进行按栏排序。PDF 字体暴露的控制空格会转为空格；不会自动删页眉页脚、修复断行连字符或清洗公式。
4. 扫描页没有文本层时会提示对应空页，不会凭空生成文字，也不执行 OCR。复杂跨栏、首字放大、表格与脚注的读取顺序仍需核对；TXT 不能直接当作已经清洗的研究语料。
5. 旧任务或起初未勾选 TXT 的任务，可从历史点击“补充 TXT（不调用 API）”，再保存结果，无需重新翻译。

历史与速度
历史记录保存文件名、页数、模型、接口、并发数、阶段耗时及完成状态，重启后可重新下载或保存结果。旧版可读 PDF 会导入历史，但未知的模型与耗时不作推断。中断的任务会标注中断，需要重新提交。
默认复用完全相同文件、接口、模型和翻译设置的已验证完成结果，并校验文件哈希；复用不会调用模型。关闭高级设置中的复用选项可以强制重新翻译。此优化主要针对重复提交，首次翻译仍需要模型推理和本地排版。
并发预设为 4/8/16；默认 8。更高并发是否更快取决于供应商限流和批次大小，不能保证倍增。对照版会增加一次渲染，按需开启。

数据与隐私
PDF 在本机进行解析和排版。翻译所需文本会发送到你配置的供应商；首次准备资源时会连接 BabelDOC 官方资源上游。
桌面版任务历史及原稿、结果持续保存在本机，不再于 24 小时后自动删除。结果另存于统一输出目录。只使用网页开发入口时仍执行 24 小时临时目录清理。
日志与任务目录：~/Library/Application Support/PaperStudio/
通过“帮助 → 打开日志与本地数据”可以定位。删除 App 不会自动删除此目录或钥匙串记录；可先使用“忘记密钥”，再自行删除数据目录。
App 不包含开发者的 API 密钥、原稿、历史译文或模型缓存；无需安装 Python、Node 或开发工具。

处理边界
当前引擎不支持表格文字的专用 OCR 翻译路径。扫描件、图片内文字、复杂表格与特殊版式请先用代表性页面试译，不能保证像素级一致。
模型列表成功只代表可读取模型信息；实际翻译权限、限流、响应格式及质量仍由供应商决定。

开源组件与源码
本 App 使用 PDFMathTranslate-next 2.9.0、BabelDOC 0.6.2、PyMuPDF 等开源组件。对应许可证与上游源码地址见 App 内 Resources/ThirdPartyLicenses/。
