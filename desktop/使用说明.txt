纸间 · PDF 译制台 0.4.2
Apple 芯片版 · macOS 14 或更高版本

0.4.2 请求与译文修复
默认输出中英对照 PDF，同时保留中文 PDF 和原文、译文 TXT。修复排队误占超时预算、成功子批次耗尽重试额度的问题；不完整译文会自动缩小批次、转单段翻译。复杂公式段落必要时保留原标记并分段翻译，请对照原文核对语序。接口响应数与已校验段落数分别展示；反复失败时提供原因，不交付无效结果。

安装与启动
1. 解压 ZIP，将“纸间.app”拖入“应用程序”，双击启动。
2. 此组内测试版采用本地临时签名，尚未经过 Apple 公证。如 macOS 阻止启动，可在尝试打开后前往“系统设置 → 隐私与安全性”，对本 App 选择“仍要打开”。只对你确认来源的这一份 App 操作。
3. 首次使用自动下载约 350 MB 的版式模型、字体和字符映射。可在下载期间配置 API。下载失败后点击“重试”，已完成并通过校验的文件会保留。

0.4.1 修复提示
修复部分 TeX 公式字体将括号提取为 NUL 时误判译文损坏的问题：按原稿同页的嵌入字体、字形及坐标核对后保留。新的或无法追溯的 NUL 仍阻止交付，提示词污染检查仍保留。
升级后会重新校验仅因旧版 NUL 规则失败的已有完整结果，能通过才恢复 PDF 和 TXT，不重新调用 API；缺失或异常的结果不会自动恢复。TXT 无法完整表达这些公式字形，请对照 PDF。

0.3 升级提示
0.4 修复了“界面资源已就绪，但翻译子进程仍重新下载并超时”的目录问题。所有翻译与保存子进程统一使用 App 数据目录中的 engine-cache；已有下载会复用，无需复制到 ~/.cache/babeldoc。升级保留 API 配置、原 PDF 和翻译历史。

配置 API
1. 点击“新建配置”，给配置起名，再填写供应商提供的 OpenAI-compatible API 基础地址。例如 https://你的供应商/v1；自定义路径会保留。仅填写域名时会自动补 /v1。
2. 填写该地址对应的 API 密钥，App 会自动请求 /models 并展示模型列表。选择支持文本对话和 chat/completions 的模型；列表中可能也包含嵌入、图像等不适用于翻译的模型。
3. 若供应商没有模型列表接口，可手动填写模型名称。
4. 勾选“安全记住 API 密钥”后点击“保存配置”，密钥将保存到当前 Mac 用户的登录钥匙串。未勾选时，保存后密钥仅保留在当前 App 会话内；普通偏好设置中只保存名称、地址、模型和速度设置，每套密钥按配置 ID 独立保管。
5. 修改 API 地址后需要重新填写对应密钥，App 不会将原地址的密钥自动发送到新地址。“忘记密钥”只清除选中项的密钥，“删除配置”只删除选中项；其他已保存项不受影响。
6. 保存后可从“已保存的 API 配置”下拉菜单切换，地址、密钥、最近模型和速度设置一起恢复。地址或密钥变化后保存会新增一项；仅修改模型或速度则更新当前项。同一地址可以保存多套密钥。
7. 有未保存修改时，切换前可选择保存、放弃或取消。翻译进行时不能切换。
8. 0.3 当前最后保存的一套配置会自动迁移；旧版早先被覆盖的密钥无法恢复，请重新添加。
9. 这是 OpenAI-compatible 接口客户端，供应商需提供兼容的 /chat/completions；原生 Anthropic、Gemini 等不同协议需使用其兼容端点。

翻译 PDF
1. 拖入或选择一份 PDF。当前目的语固定为简体中文。
2. 模型与字体就绪、API 配置完整后，点击“开始译制”。
3. 超过 80 页自动分段，完成后合并。高级设置可调并发及分段页数。
4. 默认生成中英对照 PDF，同时保留纯译文 PDF；如只需译文，可关闭高级设置中的对照版。
5. 默认在完成后自动保存到“下载/纸间译文”，每个任务使用“原文件名--日期-任务编号”文件夹，重名也不会覆盖已有结果。在“输出与历史”中可更改统一目录、关闭自动保存、重新保存或打开结果文件夹。单个文件仍可通过“另存”按钮另选位置。
6. 任务运行中退出 App 会先询问是否取消。当前版本没有断点续传；已下载的模型和字体不会因退出而删除。

TXT 与研究用途
1. 默认勾选“同时导出原文 TXT 和译文 TXT”。原文 TXT 来自原 PDF 的文本层；译文 TXT 来自最终中文 PDF 的文本层，不做第二次模型翻译。
2. 只需要原文时，选择 PDF 后点击“仅提取原文 TXT（不调用 API）”，无需配置密钥，也不消耗 API 用量。
3. TXT 使用 UTF-8，保留分页标记和原始换行，并对普通双栏进行按栏排序。PDF 字体暴露的控制空格会转为空格；不会自动删页眉页脚、修复断行连字符或清洗公式。
4. 扫描页没有文本层时会提示对应空页，不会凭空生成文字，也不执行 OCR。复杂跨栏、首字放大、表格与脚注的读取顺序仍需核对；TXT 不能直接当作已经清洗的研究语料。
5. 旧任务或起初未勾选 TXT 的任务，可从历史点击“补充 TXT（不调用 API）”，再保存结果，无需重新翻译。

历史与速度
历史记录保存文件名、页数、模型、接口、阶段耗时、完成状态，以及请求数、在途峰值、限流重试和服务商返回的 token 用量，重启后可重新下载或保存结果。旧版可读 PDF 会导入历史，但未知的模型与耗时不作推断。中断的任务会标注中断，需要重新提交。
默认复用完全相同文件、接口、模型和翻译设置的已验证完成结果，并校验文件哈希；复用不会调用模型。关闭高级设置中的复用选项可以强制重新翻译。此优化主要针对重复提交，首次翻译仍需要模型推理和本地排版。
默认同页相邻段落按约 1,536 原文 token、最多 16 段组成批次。自动模式从 4 个在途请求、每秒 2 次开始，连续成功 8 次增加 2 个在途请求，最高 16 个；高级设置可手动设定两个上限。429 限流时自动退让并等待重试；每个待修复单元最多 5 次内容请求、180 秒处理时间；排队不占用此时限。拆分后的子任务与已取得进展的剩余段落独立计数。异常段落自动缩小批次并尝试单段翻译，公式与样式始终校验，反复失败会报告具体原因。
默认“自动最低思考”：尽可能关闭或使用最低支持值。未知服务只显示“已请求最低，服务商未确认实际设置”；也可改为“服务商默认”。接口限制和模型响应不同，提速幅度应以实际样本为准。进度百分比不用于估算剩余时间。默认提供中英对照版，便于阅读和核对。

数据与隐私
PDF 在本机进行解析和排版。翻译所需文本会发送到你配置的供应商；首次准备资源时会连接 BabelDOC 官方资源上游。
桌面版任务历史及原稿、结果持续保存在本机，不再于 24 小时后自动删除。结果另存于统一输出目录。只使用网页开发入口时仍执行 24 小时临时目录清理。
日志与任务目录：~/Library/Application Support/PaperStudio/
通过“帮助 → 打开日志与本地数据”可以定位。删除 App 不会自动删除此目录或钥匙串记录；可先使用“忘记密钥”，再自行删除数据目录。
App 不包含开发者的 API 密钥、原稿、历史译文或模型缓存；无需安装 Python、Node 或开发工具。

处理边界
当前引擎不支持表格文字的专用 OCR 翻译路径。扫描件、图片内文字、复杂表格与特殊版式请先用代表性页面试译，不能保证像素级一致。
旧版引擎已有的细小元数据、混排小数点和参考文献 DOI 排版问题仍可能出现；本次样本中也可见。用于引用、统计或研究语料时，请以原 PDF 和原文 TXT 核对数字、公式及 DOI，勿直接将译文作为已校验数据。
模型列表成功只代表可读取模型信息；实际翻译权限、限流、响应格式及质量仍由供应商决定。
