# 纸间 0.4.0 验收记录

验证日期：2026-10-20。Apple 芯片 Mac；macOS 14+；PDFMathTranslate-next 2.9.0、BabelDOC 0.6.2。随附 `validation-0.4.0.json` 为去除密钥、配置 ID、本机路径和文档正文后的机器可读记录。

## 发布行为

默认使用完整优化：同页批次目标 1,536 个原文 token、最多 16 段；共享并发及请求速率控制；严格 JSON/段落/占位符校验和局部重试；默认请求接口支持的最低思考设置。旧段落缓存持续禁用，完整文档结果可复用。原流程和仅扩大批次仅用于内部对照，不出现在普通用户的设置中。

每套 API 地址、模型、速度和钥匙串密钥独立保存。地址或密钥改变后保存为新项；同地址不同密钥可并存。切换前处理未保存修改，翻译期间禁止切换。旧版只迁移最后保存的一套，无法恢复早先被覆盖的密钥。

## 自动验证与资源目录修复

- 52 项 Python 测试通过；包含原生 Swift 配置存储测试、模拟供应商隔离、迁移/重启/删除/回滚、协议与调度测试。TypeScript 和 ESLint 通过；网页构建与两个渲染测试通过。
- 协议覆盖乱序、漏段、重复/错误 ID、错误 JSON、公式占位符损坏、截断、长段拆分、原样数字/URL/DOI、思考参数协商、429/502、超时、鉴权和取消；回退共用控制器及请求预算。
- 冻结引擎实际运行：子进程、SSE、纯译文和对照 PDF、元数据和链接、两种 TXT、重启后历史/下载以及整份结果复用通过。模拟供应商收到 1 次真实内容请求，没有额外 Hello 请求；任务文件不含测试密钥。
- 0.3 问题根因是主进程和翻译/保存子进程的资源根目录不同。0.4 在所有进程入口提前设置同一 `engine-cache`，再导入引擎和启动子进程。
- 隔离验收使用已校验的 App 资源缓存，并由 macOS 沙盒禁止读取旧 `~/.cache/babeldoc` 内容、禁止访问外网，仅允许本机模拟接口。完整翻译和保存成功，日志中没有资源下载失败或辅助进程崩溃。该验证确认不会依赖作者的旧默认缓存；没有模拟各校网络的首次下载稳定性。首次资源下载仍需可访问上游，失败可重试。

## 固定延迟对照

相同四页中间表示，每页 24 段、每段约 100 token；每次供应商响应固定等待 1.2 秒，返回原生 JSON，段落 ID 反序返回并验证归位。每种两次。

| 流程 | 请求数 | 第一次 / 秒 | 第二次 / 秒 | 均值 / 秒 |
| --- | ---: | ---: | ---: | ---: |
| 原流程 | 32 | 10.443 | 10.466 | 10.455 |
| 仅扩大批次 | 8 | 3.190 | 3.190 | 3.190 |
| 完整优化 | 8 | 5.424 | 5.426 | 5.425 |

完整优化请求减少 75%，耗时减少 48.1%，达到约定的 50% / 30% 门槛。该测试检验组织与调度，不代表真实译文质量或所有服务商速度。

## 真实接口对照

按用户后续要求仅使用当前可用的一套服务：`www.sssai.xin` 的 `deepseek-v4.1-flash`。四页样本来自同一份 17 页 PDF 的第 1、4、7、12 页，均关闭结果复用，生成中文 PDF、对照 PDF 和两种 TXT。原流程与仅扩大批次保留原先 16 并发及服务商默认思考；完整优化使用自动并发、2 次/秒和自动最低思考。计时包含解析、翻译和保存，非仅网络时间。两次重复不足以估计长期稳定性。

| 流程 | 第一次 / 秒 | 第二次 / 秒 | 平均 / 秒 | 平均实际 HTTP 请求 |
| --- | ---: | ---: | ---: | ---: |
| 原流程 | 63.26 | 61.63 | 62.45 | 20.5 |
| 仅扩大批次 | 73.44 | 91.32 | 82.38 | 17.5 |
| 最终完整优化 | 32.59 | 34.75 | 33.67 | 13.0 |

最终完整优化总耗时减少 **46.1%**，请求数减少 **36.6%**，翻译阶段均值由 37.62 秒降至 18.07 秒。两次均没有 429；服务商返回用量逐次保留在 JSON 中。实际接口未达到模拟环境的请求减少 50%，不据此声称真实调用固定减半。

**负结果与修正：**仅扩大批次平均慢 31.9%，未作为独立产品模式发布。最初仅发送 `thinking:disabled` 的完整流程也慢至 98.86 秒，服务商仍返回约 5 万 reasoning token，该候选被淘汰。最终同时发送兼容的 `reasoning_effort:none` 和 `thinking:disabled` 后完成上述两轮。服务商未回显实际设置，也未返回 reasoning 用量字段；界面据实显示“已请求最低，服务商未确认实际设置”，不将缺少字段解释为零。

官方 DeepSeek 上修正后一轮为 31.39 秒；随后 HTTP 402 导致第二轮与整份测试不能完成。用户更换可用配置后，才在同一新服务上重新完成所有对照。该未完成组合不混入最终均值。GPT 对照按用户后续要求取消。不同模型、服务和文档不承诺固定倍数提速。

## 17 页端到端与质量边界

整份 17 页最终优化用时 **68.95 秒**，其中翻译阶段 39.26 秒；59 次 HTTP 请求，59 次成功，0 次 429，1 次协议局部重试。中文 PDF、对照 PDF、原文 TXT 和译文 TXT 均生成并自动保存。配置恢复、模型列表、任务历史、从历史打开结果及原生另存 TXT 已实际操作；另存文件与任务原文件逐字节一致。

- 中文版 17 页、62 个链接、4 幅图；对照版 17 个双幅页面、124 个链接、8 幅图。中文版页面尺寸与原件一致，链接目标全部匹配，对照版对应加倍。输入没有书签，未据此宣称验证了复杂书签。
- 两种 TXT 均为 UTF-8，包含 17 个分页标记，没有禁止的控制字节。原文 TXT 取自输入文本层，译文 TXT 取自最终 PDF 文本层；未清洗成研究语料。
- 渲染了全部 17 页中文版，逐页接触表和重点单页检查；另查对照版第 1、10、17 页，正文、表格和图形可见。高置信提示词污染扫描没有命中。
- 数字和引文检查发现：首页细小出版元数据、部分参考文献 DOI 的混排，以及一处 `1.25` 的小数点字形存在问题。相同现象在旧 0.3 输出及原流程可见，属于仍未解决的上游版式边界。不能宣称所有数字、公式或引文已经逐项保真；重要引用、统计和研究用途仍须对照原件核对。没有发现本次加速引入的同类新增版式回退，但该样本不构成全面质量保证。
